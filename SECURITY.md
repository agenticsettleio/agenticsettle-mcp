# Security Policy

## Reporting a vulnerability

Please report suspected security issues privately to **agenticsettleio@gmail.com**. Do not open a public issue for a vulnerability.

Include what you found, how to reproduce it, and the affected version (see `pyproject.toml`). This is a small project run by one person, so there is no guaranteed response time, but reports are read and answered as soon as possible.

## Scope

This repository is the verification-only MCP server. It does not move money, tokens, or any financial asset. Issues in the hosted service at `https://app.agenticsettle.io` can be reported to the same address.

Please do not test against the hosted service with automated scanning or load, and do not access data that is not yours.
